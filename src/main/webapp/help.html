Help & Instructions

Step-by-step guide for staff and administrators.

1. Logging In & Registration

  1. Start WAMP Server (MySQL must be running — green icon).
  2. Run DentalClinicApplication.java from IntelliJ.
  3. New staff can register at register-staff.html (instant STAFF access).
  4. Admin login redirects to the admin dashboard; staff login goes to the staff dashboard.

2. Registering a New Appointment

  1. Click Register Appointment in the sidebar.
  2. Fill in all patient fields. Mobile must be exactly 10 digits.
  3. Select date/time, then click Check Available Dentists.
  4. Choose an available dentist and treatment, then submit.

3. Searching Appointments

  1. Open View Appointment.
  2. Enter appointment number, patient name, and/or mobile (at least one required).
  3. Select a result card to view full details.

4. Calculating and Printing a Bill

  1. Click Calculate Bill and enter the appointment number.
  2. Adjust consultation fee and apply a percentage or fixed discount.
  3. Click Save Bill, then Preview/Print Receipt.

5. Admin Tasks

  1. Manage Staff: edit accounts, activate/deactivate, reset passwords, delete staff.
  2. Manage Dentists: add/edit dentists, set working hours, activate/deactivate.

Technology Used

  • Frontend: HTML + CSS + JavaScript (no JSP)
  • Backend: Java Servlets, Services, DAOs (JDBC)
  • Database: MySQL via WAMP Server
  • Security: BCrypt passwords, session auth, server-side role checks
